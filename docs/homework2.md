# Homework 2 要求对应

依据用户提供的 Homework 2 课件，选择代码方向的三 Agent 顺序工作流，在作业 1 框架上扩展。

| 评审维度 | 权重 | 本项目实现 | 可展示证据 |
| --- | --- | --- | --- |
| 流程完整性 | 40% | 任务输入 → 需求规划 → 实现及测试文件 → 独立审查 → 文件交付 | 在线真实任务、离线固定闭环、ZIP 交付 |
| Agent 协作 | 30% | 三种职责、独立请求、结构化共享状态、明确的上游依赖 | 角色卡片、共享状态、执行日志 |
| 可扩展性 | 20% | 合同、模型适配、编排、存储和界面分层 | `codeflow/` 模块、状态机、扩展说明 |
| 文档 | 10% | 启动、配置、架构、流程、限制、验收与演示 | README、Design、本文及验收文档 |

必须项已在设计与实现中覆盖：不少于两个 Agent 协作，角色间消息传递 / 状态共享，基本顺序执行。项目采用三个角色。

推荐项选择：条件分支、有限修复循环、可视化工作台、日志和追踪、错误处理、检查点恢复。并行调度并非必需，本项目保留有依赖的顺序执行。

## 一分钟演示脚本

| 时间 | 演示内容 |
| --- | --- |
| 0–10 秒 | 打开黑白工作台，说明任务输入、三个角色及作业 1 的复用 |
| 10–23 秒 | 打开已有真实在线任务，展示需求规划、实现和审查输出 |
| 23–36 秒 | 查看生成文件、原始代码差异和带行号的审查问题 |
| 36–49 秒 | 切换离线固定案例，展示一次退回、修复、复审的日志与共享状态 |
| 49–60 秒 | 下载实现与测试，展示恢复入口与设计流程图 |

视频为可选提交物，当前文档只是录制脚本，不表示已经录制视频。若对在线等待做剪辑，应注明。
